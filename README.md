---

### Overview
---

- Web-based Learning Management System for Virtual Autopsy (PMCT) training
- Self-paced online training platform
- Designed for students and administrators
- Structured course, module, assignment, examination, and certification workflow
- Premium medical technology and forensic science focused interface
- Responsive design for desktop, tablet, and mobile devices

---

The current implementation focuses on the frontend UI and user experience of the Virtual Autopsy Online Training LMS. Backend APIs, database integration, authentication, payment processing, email services, file storage, video streaming, and other server-side functionality will be integrated separately.
